### US-002: Create RSS proxy endpoint
Status: in_progress
Depends on: US-001

Description:
As a user, I want the app to fetch and parse RSS feeds so I can view items in the UI.

Acceptance Criteria:
- [ ] Add `GET /api/rss?url=...` that validates the url query parameter
- [ ] Parse the RSS feed and return JSON with feed metadata and items
- [ ] Example: requesting a valid feed returns JSON with `feed.title` and a non-empty `items` array
- [ ] Negative case: missing or invalid `url` returns 400 with `{"error":"invalid_url"}`
- [ ] Negative case: fetch or parse failure returns 502 with `{"error":"fetch_failed"}`
