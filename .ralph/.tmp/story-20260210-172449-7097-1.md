### US-001: Initialize project and basic server
Status: in_progress
Depends on: None

Description:
As a developer, I want a minimal project scaffold so I can run the app locally.

Acceptance Criteria:
- [ ] Create a new npm project with scripts: dev, start, test
- [ ] Install dependencies with `npm install express rss-parser`
- [ ] Add a basic Express server that serves `public/` at `/`
- [ ] Add a `tests/smoke.test.js` script and wire `npm test` to run it
- [ ] Example: running `npm test` exits with code 0 when `server.js` and `public/index.html` exist
- [ ] Negative case: if `public/index.html` is missing, `npm test` exits non-zero with a clear message
