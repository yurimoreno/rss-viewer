### US-001: Add OPML file upload and parsing
Status: in_progress
Depends on: None

Description:
As a user, I want to upload an OPML file so my feeds are added automatically.

Acceptance Criteria:
- [ ] Add a file input in the UI labeled 'Import OPML'
- [ ] Parse OPML XML client-side and extract feed URLs from xmlUrl attributes
- [ ] Merge imported URLs into recent feeds (dedupe, most-recent-first, max 5)
- [ ] Example: importing an OPML file with 3 feeds adds them to the recent list
- [ ] Negative case: uploading a non-OPML file shows an error and does not change recent feeds
