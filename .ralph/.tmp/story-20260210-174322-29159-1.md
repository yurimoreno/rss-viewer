### US-003: Build the minimal viewer UI
Status: in_progress
Depends on: US-002

Description:
As a reader, I want a simple page to enter a feed URL and read recent items.

Acceptance Criteria:
- [ ] Create `public/index.html`, `public/styles.css`, and `public/app.js`
- [ ] UI includes URL input, load button, status banner, and results list
- [ ] States: loading shows spinner/text, error shows message and clears items
- [ ] Example: entering a valid feed URL renders a list of items with title, date, and summary
- [ ] Negative case: entering an invalid URL shows an error state and no items
